# VoxelCraft — 设计文档

一个像《我的世界》的体素沙盒。目标：**宏大**、可无限延伸、专心建造（创造模式）。
引擎：**Godot 4.6 + 纯 GDScript**，从零实现，不依赖第三方体素库。

## 第一性原理：从《我的世界》产品 → 反推技术

| 产品呈现的样子 | 必须有的系统 | 技术实现 |
|---|---|---|
| 整个世界都是方块、连到天边、有山有水 | 体素数据 + 程序化生成 | 3D 方块ID网格；FastNoiseLite 噪声；按区块存 → 可无限 |
| 第一人称走动，踩地撞墙、跳、创造飞行 | 物理角色 + 碰撞 | CharacterBody3D；每区块按实心块生成碰撞体 |
| 指哪挖哪、指哪放哪，瞬间生效 | 准星射线 + 编辑 | 摄像机射线命中方块/面；改格后即时重建该区块网格；材料库带分类、分类/特性/用途语义搜索、搜索自动预览首个匹配项、方向键浏览可见材料、搜索回车选材、最近使用与当前材料详情预览；灯笼/月石灯/蓝晶支持夜景发光 |
| 玩家能快速起形，不必一格格堆 | 建造画笔 + 模板库 | 3×3 画笔；平台、立柱、拱门、墙面、楼梯、房架、小屋、营火、小桥、花圃、灯塔、路标模板；小屋/营火/小桥/花圃/灯塔/路标使用固定多材质组合，一键就是成品场景件；模板条剪影图标；材质色逐格幽灵预览；阻挡格单独红色提示；支持朝向旋转和整组撤销 |
| 几百万方块还能流畅跑 | **可见面合并网格（核心）** | 每区块=一整块 Mesh，只生成"挨着空气/透明块"的面 |
| 每种方块有像素贴图（草顶/侧/底不同） | 贴图图集 + 每面UV | 程序生成 atlas 纹理，按面贴 UV，最近邻采样不糊 |
| 天空、太阳、远处雾 —— 宏大感 | 环境氛围 | WorldEnvironment 天空+雾 + 平行光太阳；动态雨雪，雪峰区域会把降水转为山雪表现；湿地、雪峰、岩岭、针叶林/苔林等区域主题微光；遗迹带暖/冷光点缀，夜间可辨识 |
| 能无限扩展（怪、群系…） | 数据驱动 + 模块解耦 | 方块用数据表、生成器可插拔、预留扩展口 |

## 模块（每个职责单一、可单独测）

- **BlockLibrary** `scripts/BlockLibrary.gd` — 方块定义（数据表）+ 程序生成的像素图集 + 共用材质。加方块只加一行；换真实贴图只改图集函数。
- **Chunk** `scripts/Chunk.gd` — 一个区块的纯方块数据（16×16×96）。无节点，纯逻辑、可测、可放线程。
- **ChunkMesher** `scripts/ChunkMesher.gd` — 数据 → 网格 + 碰撞体。只出可见面（隐藏面剔除）。横向看 4 个邻居避免接缝。
- **WorldGenerator** `scripts/WorldGenerator.gd` — 噪声地形：丘陵 + 山脊(ridged)高山 + 海平面湖水 + 沙岸 + 撒树 + 倒木 + 自然石丘 + 泉池/湿地微景观 + 地下蓝晶晶洞；每种区域提供短地貌描述和可收集的踏足进度，用于 HUD、手记、地图和暂停/标题摘要。**可插拔**。
- **World** `scripts/World.gd` — 管理区块：生成、造网格、读写方块、跟玩家**流式加载/卸载**。数据多铺一圈保证接缝正确；世界存档用临时文件写入和 `.bak` 备份回退，进入恢复世界后 HUD/音效会提示并保持需保存状态；遗迹、旅程、封面和已踏足区域都作为元数据保存，降低写入中断导致的存档损坏风险。
- **Player** `scripts/Player.gd` — 第一人称：鼠标视角、WASD、跳、双击空格飞、挖/放、准星高亮、快捷栏选块；模板库包含可单材质快速起形的结构件，以及小屋、营火、小桥、花圃、灯塔、路标等固定多材质成品件。
- **HUD** `scripts/HUD.gd` — 准星 + 底部快捷栏（图标取自图集），高亮当前块；状态栏内置紧凑导航罗盘，持续显示方位、归途、附近线索和当前修复目标；跨区域时显示带地貌描述的进入反馈；8 步旅程引导把探索、材料库、建造模板、地图、遗迹和存档串成首局目标线，并在目标文本里给出 WASD/E/M/右键等最短操作入口；发现遗迹后转入带进度、方向和距离的修复目标。
- **DiscoveryTracker / TravelJournal / WorldMap** — 遗迹发现、方向线索、世界内信标、手记记录和地图投影；每处遗迹会生成稳定的类型、守护物和档案短句，增强探索收藏感；手记用"世界印记"统计建造量、区域足迹、旅程进度和修复成果，并用区域足迹芯片展示已踏足地貌和剩余区域数量；世界地图带玩家周边地貌采样底图，让草原、湿地、水岸、岩岭和雪峰在地图上可区分；遗迹周围玩家改造会动态计算修复度，手记/地图会给出当前修复目标、距离方向、修复状态和路线高亮，世界内修复信标用十段环形刻度显示进度，满修复会触发世界内完成光效并留下完成信标；营火模板带点燃火花和轻烟反馈。
- **ActionEffects** `scripts/ActionEffects.gd` — 世界内挖掘、放置、阻挡、营火和遗迹修复的短生命周期体素碎片反馈；碎片颜色随石材、木材、玻璃、植物、雪、黏土和蓝晶等材料变化；大模板放置使用一次中心聚合碎片，避免小屋/灯塔这类成品件逐格刷粒子造成卡顿。
- **AudioFeedback** `scripts/AudioFeedback.gd` — 无外部素材的程序化短音效；覆盖建造、阻挡、存档、撤销/重做、发现、旅程完成和天气变化；放置/挖掘会按石材、木材、玻璃、植物、流体和发光方块切换音色；大模板放置使用更厚重的结构落地音，并压制同帧逐格放置音。
- **PhotoOverlay** `scripts/PhotoOverlay.gd` — 拍照模式取景层；进入沉浸截图时显示三分线、中心标记、安全边框和暗角，保存截图时由 Main 临时隐藏，截图反馈会在 HUD 恢复后补显示。
- **TitleScreen / PauseMenu / GameSettings** — 首屏世界选择、数字/文字新世界种子实时封面/地貌预览、左右方向键切换已有世界、回车继续当前选中世界、种子回车创建、删除确认、首屏设置入口；标题页和封面展示遗迹修复摘要，并能列出主存档损坏但 `.bak` 可恢复的世界，选中时提示“备份恢复 / 需保存”；暂停菜单采用双栏结构，左侧用世界状态卡片呈现旅程、遗迹、修复和归途，右侧集中视距、画质、音量、灵敏度和天气设置；暂停菜单可保存、打开材料库/手记/地图并返回暂停上下文、保存后即时同步世界摘要、返回标题/世界选择并刷新封面目录，复用同一套设置落盘。
- **Main** `scripts/Main.gd` — 启动入口：天空/雾/太阳 + 接好 World/Player/HUD。

## 怎么运行

- 编辑器：用 Godot 打开 `VoxelCraft` 工程，按 **F5**。
- 命令行：`godot --path VoxelCraft`
- 截宏大全景：`VC_RADIUS=5 godot --path VoxelCraft --script res://tests/shot_world.gd`
- 自检：`godot --headless --path VoxelCraft --script res://tests/test_mesher.gd`（造网格逻辑）；`test_play.gd`（进游戏路径）

## 里程碑

- ✅ **M1 宏大可玩切片**（已完成、已验证）：流式无限风格地形、山脉、水、像素贴图、第一人称、挖/放、HUD、天空雾太阳。
- ⏭ **M2 性能与规模**：多线程/后台生成（消除开局停顿）、更大加载半径、贪心网格、开背面剔除。
- ⏭ **M3 世界更丰富**：高处石头/雪顶、洞穴、矿物、跨区块的树、群系。

## v1 简化（已知、留待后续）

- 造网格用**双面渲染**（免去绕序），以后开背面剔除再省一半三角形。
- 开局**同步**生成脚下一小片（约 2 秒），四周流式补全；远处用雾盖住加载边界。
- 树叶只在本区块内（跨区块的会被裁掉）。
- 贴图是**程序生成**的像素图，随时可换成真实 PNG（BlockLibrary 是唯一改动点）。

## 保留的扩展口（"各种可能性"）

数据驱动的方块表、可插拔的生成器、预留存档/实体系统接口 —— 以后要加昼夜、背包、合成、怪物、NPC、多人，都不用推倒重来。
