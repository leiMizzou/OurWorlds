# 主题岛 SP2 — 新方块（霓虹/发光 + 铁轨）实现计划

> 续 SP1。目标：给 BlockLibrary 增加赛博城需要的霓虹发光方块和连接区铁轨方块，供 SP3 的标志建筑使用。数据驱动、TDD。

**Goal:** 新增 4 个方块——3 个霓虹自发光块（青/品红/绿）+ 1 个铁轨块——并接入程序图集、发光材质桶、材料库、agent 契约。

**Architecture:** 完全沿用 BlockLibrary 的"数据驱动加方块"机制（`scripts/BlockLibrary.gd` 头注释：加方块只在 `_build_defs()` 加一行，贴图在 `_tile_color()`）。霓虹块进发光桶（`mat_bucket_lut==1`，用 `material_emissive`）。

## 关键现状（已核对）
- 方块 id 常量 0–34（最高 `SUNSTONE=34`）；贴图 tile 常量 `T_*` 0–33。
- `_build_defs()`：每块一行 `_defs[ID] = {"name","top","side","bottom","solid","transparent"}`。
- `_build_luts()`：`var n := SUNSTONE + 1`（**必须改为新最高 id + 1**）；发光桶是硬编码集合：
  `mat_bucket_lut[eid] = 1 if (eid==LANTERN or MOONSTONE_LAMP or BLUE_CRYSTAL or SUNSTONE) else 0`（**新霓虹块要加进这个条件**）。
- `_tile_color(tile,px,py)`：按 tile 分派到 `_t_xxx(px,py)` 画师；发光块可参考 `_t_sunstone`/`_t_moonstone_lamp`，金属块参考 `_t_steel_block`/`_t_polished_iron`。
- 材料库：`creative_blocks()` 列表 + `creative_categories()` 分类 + `hotbar_blocks()`；新块要加入。
- agent 契约：`scripts/AgentBridge.gd` 的 `BLOCK_ALIASES`（const dict 0–34）要加新别名。

## 新方块
| id | tile | 名称 | solid | transp | 发光 | 画师要点 |
|---|---|---|---|---|---|---|
| `NEON_CYAN=35` | `T_NEON_CYAN=34` | 霓虹青 | true | false | 是 | 暗底 + 亮青网格线，强发光 |
| `NEON_MAGENTA=36` | `T_NEON_MAGENTA=35` | 霓虹品红 | true | false | 是 | 同上，品红 |
| `NEON_LIME=37` | `T_NEON_LIME=36` | 霓虹绿 | true | false | 是 | 同上，黄绿 |
| `RAIL=38` | `T_RAIL=37` | 铁轨 | true | false | 否 | 深色金属底 + 两条平行亮轨 + 枕木 |
